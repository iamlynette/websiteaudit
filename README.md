# Website Audit

Minimal starter project for Codex onboarding. The final website code can replace this starter later.

## Requirements

Node.js 18 or later. No external dependencies are required.

## Start

Run `npm start` (or `npm run dev`). Open http://localhost:3000. Set `PORT` to use a different port.

## Validate

Run `npm run check`, start the server, and confirm that `GET /` returns HTTP 200. This starter has no automated test suite or build step.
